# Using Timers

## Starting a Timer

From the top navigation bar select the clock icon to start a timer. A new screen
will appear with a timer, the date and buttons to assign this timer to a
feeding, sleep or tummy time activity. On the bottom of the timer is a red
button to delete the timer, a blue button to edit the timer and add a name or
change the start time, an orange button to restart the timer and a yellow button
to stop the timer.

## Keep Screen On

The "Keep screen on" toggle allows you to prevent your device from automatically
locking or going to sleep while viewing the timer. This is especially useful for
longer timers or when you need to keep your screen active during an activity.

**How to use:**

1. Start or view a timer
2. Enable the "Keep screen on" toggle at the top of the timer page
3. Your device screen will remain active while the toggle is enabled
4. The toggle state is remembered for your current browser session
5. To allow your device to sleep normally, simply disable the toggle

**Browser Support:**

This feature uses the Screen Wake Lock API and is supported on:
- Chrome/Chromium (Android and Desktop)
- Edge (Android and Desktop)
- Opera (Android and Desktop)
- Safari (Limited support)

If your browser doesn't support this feature, you'll see a console message indicating the API is not available.

**Note:** This feature respects your device's permission system and battery management settings.

## Creating Entries from Timers

### Create a Feeding Entry

<video style="max-width: 320px;" autoplay controls loop muted playsinline>
  <source src="../../assets/videos/timer_feeding.mp4" type="video/mp4">
</video>

From the top navigation bar select the clock icon to start a timer. When the
activity is complete, select Feeding. As necessary, modify the child and
start/end time of the timer. Update the feed to reflect the type of feeding
(i.e. breast milk, bottle, etc.), the feeding method and amount. When ready,
select Submit.

### Create a Sleep Entry
